## Detalhes de Implementação

Consultar a seção **"Inserção nas Skills"** e **"Diferenças entre Bootstrap e Invocação"** da techspec.md.

Cada SKILL.md recebe o **mesmo bloco** inserido como primeiro passo do "Fluxo de Trabalho" (ou seção equivalente):

```markdown
### 0. Validação de Skills Empresariais (Obrigatório)

Siga as instruções em @.claude/validation/enterprise-skills-check.md para validar e instalar
as skills empresariais obrigatórias. NÃO prossiga para o próximo passo se a validação
bloquear a execução.
```

**Para cada SKILL.md:**
1. Ler o conteúdo atual do arquivo
2. Localizar a seção "## Fluxo de Trabalho" (ou "## Etapas" ou seção equivalente onde os passos são definidos)
3. Inserir o Passo 0 ANTES do primeiro passo existente
4. NÃO alterar a numeração dos passos existentes (o Passo 0 é adicionado antes do Passo 1)

**Comportamento padrão de invocação** (diferente do bootstrap):
- Mensagens concisas (resumo, não lista detalhada)
- Fallback offline permitido (se skills já instaladas localmente com hash válido)

## Critérios de Sucesso

- Todos os 7 SKILL.md contêm o Passo 0 referenciando `@.claude/validation/enterprise-skills-check.md`
- O Passo 0 está posicionado ANTES do primeiro passo existente em cada skill
- A numeração dos passos existentes não foi alterada
- Nenhuma outra parte dos SKILL.md foi modificada (apenas inserção)
