## Visão Geral

Modificar o `kspec-bootstrap/SKILL.md` para incluir a validação de skills empresariais como passo obrigatório no fluxo de bootstrap. O bootstrap tem comportamento diferente das demais skills: sempre executa a instalação completa e bloqueia em caso de falha (sem fallback offline), pois é o ponto de setup inicial do projeto.

## Detalhes de Implementação

Consultar a seção **"Diferenças entre Bootstrap e Invocação"** da techspec.md para entender o comportamento específico do bootstrap:

| Aspecto | Bootstrap |
|---|---|
| Mensagens | Detalhadas (lista cada skill) |
| Fallback offline | Bloqueia (é setup inicial) |
| Comportamento se ausente | Sempre instala |

O passo inserido deve seguir o padrão:

```markdown
### X. Validação de Skills Empresariais (Obrigatório)

Siga as instruções em @.claude/validation/enterprise-skills-check.md para validar e instalar
as skills empresariais obrigatórias.

**Comportamento específico do bootstrap:**
- Exibir mensagem detalhada para cada skill instalada/atualizada
- NÃO permitir fallback offline — se o repositório empresarial não estiver acessível, bloquear o bootstrap com mensagem de erro
- NÃO prossiga para o próximo passo se a validação bloquear a execução
```

**Importante:** ajustar o número do passo de acordo com a numeração existente no SKILL.md (inserir entre os passos existentes sem quebrar a sequência).
