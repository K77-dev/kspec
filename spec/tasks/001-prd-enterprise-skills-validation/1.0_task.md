## Detalhes de Implementação

### 1.2 — Bloco de validação (`enterprise-skills-check.md`)

Este é o componente central. Deve conter instruções Markdown declarativas que o agente Claude segue. Consultar a seção **"Design Detalhado do Bloco de Validação"** da techspec.md para o algoritmo completo com os 7 passos:

1. Ler lock local e extrair `remote.url` e `remote.branch`
2. `git clone --depth 1` ou `git pull` no cache local
3. Ler `skills-lock.json` do clone
4. Comparar hashes (local vs remoto)
5. Executar ações (instalar, atualizar, remover)
6. Atualizar lock local
7. Fallback offline

O bloco deve incluir os padrões de mensagens da techspec:
- `✓ Skills empresariais validadas`
- `→ Instalando [skill]... OK`
- `⚠ Não foi possível verificar skills (erro de rede)`
- `✗ Skills empresariais obrigatórias não encontradas`

### 1.3 — Lock file inicial

Criar com a estrutura definida na techspec (seção "Interfaces Principais"):
```json
{
  "version": 1,
  "remote": {
    "url": "https://github.com/K77-dev/enterprise-platform-skills.git",
    "branch": "main",
    "provider": "github"
  },
  "lastChecked": null,
  "skills": {}
}
```

### 1.4 — `.gitignore`

Adicionar apenas a linha:
```
.claude/.enterprise-skills-cache/
```
