## Visão Geral

Orquestrador comum a `init` e `update`. Executa: (1) copia `.agents/` do tarball para o projeto-alvo, (2) chama `platform.linkOrCopy` para gerar symlinks `.claude/{skills,agents,rules,templates,validation}` e `.codex/skills/<nome>`, (3) usa `agent-toml` para regenerar todos os `.codex/agents/*.toml` a partir dos `AGENT.md`, (4) garante `AGENTS.md` e `CLAUDE.md` na raiz (sem sobrescrever existentes), (5) integra com `migration.ts` quando aplicável. Idempotente — segunda execução não modifica FS.

### Conformidade com Skills Padrões

- `.claude/rules/code-standards.md` — função `runInstall` deve permanecer < 50 linhas (delegar para helpers privados).
- `.claude/rules/logging.md` — saída pt-BR com prefixos `→`/`✓`/`⚠`/`✗`.
</skills>

<requirements>
- `runInstall(opts: InstallOptions): Promise<InstallReport>` onde `InstallOptions { force?: boolean }`.
- Ordem fixa: copia `.agents/` → symlinks `.claude/` → symlinks `.codex/skills/` → gera `.codex/agents/*.toml` → ensure `AGENTS.md`/`CLAUDE.md`.
- Preserva `.claude/settings.json` e `.claude/settings.local.json` (verifica `isFile()` antes de qualquer ação; nunca converte em symlink).
- Falha localizada: erro em 1 `.toml` não bloqueia os demais; reporta em `InstallReport.errors[]` e continua.
- Idempotência: comparar `fs.readlink(dest)` com target esperado; só recria se divergir. Para `.toml` gerados, comparar hash do conteúdo antes de reescrever.
- Quando `opts.force !== true` e `migration.detectMigration()` retorna plano: chamar `migration.confirmMigration()` e abortar com exit 1 e mensagem clara se recusado.
- Logs em pt-BR (RF4.x da PRD): `→ Instalando .agents/`, `✓ Symlink criado: .claude/skills/kspec-prd → ../../.agents/skills/kspec-prd`, `✓ Gerado: .codex/agents/kspec-task-runner.toml (sandbox=workspace-write)`, `⚠ Windows detectado — usando cópia em vez de symlinks`, `✗ Migração cancelada pelo usuário`.
</requirements>
