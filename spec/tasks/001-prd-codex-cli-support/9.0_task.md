## Visão Geral

Refatorar os comandos da CLI para delegar ao orquestrador `install.ts`. `init.ts` chama `runInstall({force: opts.force})`; `update.ts` chama o mesmo `runInstall({})` confiando na idempotência. `paths.ts` ganha helpers `getAgentsSourceDir()`, `getCodexSourceDir()`, `getAgentsMdSource()`. `prompt.ts` ganha `prompt()` simples para input texto livre (usado pela migração).
