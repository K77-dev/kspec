## Visão Geral

Parser de frontmatter YAML mínimo (apenas `name` e `description`) e gerador de TOML para `.codex/agents/<nome>.toml` a partir de `.agents/agents/<nome>/AGENT.md`. Sem dependências externas: regex + template literal com escape de string TOML. Inclui mapa explícito hardcoded de sandbox por agent.

<skills>
### Conformidade com Skills Padrões

- `.claude/rules/code-standards.md` — TypeScript ESM, camelCase, evitar parâmetros > 3 (usar `interface` `AgentDocument`).
</skills>

<requirements>
- `parseAgentFile(filePath: string): AgentDocument` — lê arquivo, extrai frontmatter via regex `^---\n([\s\S]*?)\n---\n`, parseia apenas `name:` e `description:`. Rejeita frontmatter ausente/malformado com erro descritivo (mensagem cita arquivo e razão).
- `renderAgentToml(doc: AgentDocument, sandboxMode: SandboxMode): string` — produz string TOML válida com chaves `name`, `description`, `sandbox_mode`, `developer_instructions`.
- Escape de `description`: `\` → `\\`, `"` → `\"`. Sem quebras de linha permitidas em `description`.
- `developer_instructions` em string literal multi-linha `"""..."""`. Se o corpo contém literal `"""`, lançar erro controlado citando arquivo (sem corrupção silenciosa).
- Mapa `SANDBOX_BY_AGENT`: `kspec-task-runner` → `workspace-write`, `kspec-review-runner` → `read-only`, `kspec-qa-runner` → `workspace-write`.
- Agent fora do mapa: retornar default `workspace-write` e emitir warning via stderr (ou callback opcional para o caller logar).
</requirements>
