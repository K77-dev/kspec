## Visão Geral

Camada única que conhece `process.platform`. Expõe `linkOrCopy(source, destination)` que cria symlink relativo em POSIX e cópia recursiva em Windows, com idempotência (segunda chamada retorna `skipped-idempotent` quando o destino já corresponde ao esperado). Também expõe `isOnWindows()` para o resto da CLI consultar sem duplicar a heurística.

<requirements>
- Função `linkOrCopy(source: string, destination: string): Promise<LinkResult>` onde `LinkResult = "symlinked" | "copied" | "skipped-idempotent"`.
- POSIX (não-Windows): cria symlink **relativo** de `destination` para `source` (calcular com `path.relative(path.dirname(destination), source)`).
- Windows (`process.platform === 'win32'`): cópia recursiva via `fs-extra.copy`.
- Idempotência: se `destination` já existe e é o symlink/cópia esperada, retornar `skipped-idempotent` sem mexer no FS.
- `isOnWindows(): boolean` baseado em `process.platform === 'win32'`.
- Logs (quando chamado por callers): `→`/`✓`/`⚠` em pt-BR (não logar dentro do `linkOrCopy`; deixar para o orquestrador).
</requirements>
