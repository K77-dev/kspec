## Visão Geral

Detecta projetos consumidores onde `.claude/<sub>` é diretório real (não-symlink) com conteúdo modificado pelo usuário, gera plano de migração numerado e pede confirmação interativa antes de prosseguir. Garante que `.claude/settings.json` e `.claude/settings.local.json` ficam preservados independentemente da resposta.

<skills>
### Conformidade com Skills Padrões

- `.claude/rules/code-standards.md` — early-returns, evitar parâmetros > 3 (usar `MigrationPlan`).
</skills>

<requirements>
- `detectMigration(targetClaude: string): Promise<MigrationPlan | null>` — varre `.claude/{skills,agents,rules,templates,validation}` e classifica entradas que são `isDirectory() && !isSymbolicLink()`.
- Retorna `null` quando nada precisa migrar (já symlinks ou ausente).
- `MigrationPlan` inclui `realDirs[]`, `filesPreserved[]` (sempre os 2 `settings*.json` se existirem) e `actions[]` (lista numerada para exibir).
- `confirmMigration(plan: MigrationPlan): Promise<boolean>` — exibe o plano com `chalk` em pt-BR, lê resposta via `readline` (s/n), default seguro: `false`.
- Quando `force === true` no orquestrador (Task 8.0), `confirmMigration` é pulado (decisão tomada lá; este módulo apenas expõe).
</requirements>
