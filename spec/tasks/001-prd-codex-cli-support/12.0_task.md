## Visão Geral

Criar dois scripts shell para garantir qualidade antes de publicar: (1) `scripts/smoke.sh` roda `kspec init` em tmpdir e valida toda a estrutura esperada via asserts (`find`, `grep`); (2) `scripts/prepublish-check.sh` valida que os symlinks em `.claude/` e `.codex/` resolvem para `.agents/` antes do `npm publish`, mitigando o risco R5 (drift no tarball). Conectar o segundo via hook `prepublishOnly` em `package.json`.

<requirements>
- `scripts/smoke.sh` executa:
  1. `mkdir -p /tmp/kspec-smoke && cd /tmp/kspec-smoke && npm init -y`
  2. `npm link @k77-dev/kspec && kspec init`
  3. Asserts: `find .agents -type f | wc -l ≥ 23`, `find .claude -maxdepth 2 -type l | wc -l ≥ 12`, `[ -f .codex/agents/kspec-task-runner.toml ]`, `grep -q 'sandbox_mode = "workspace-write"' .codex/agents/kspec-task-runner.toml`, `grep -q 'sandbox_mode = "read-only"' .codex/agents/kspec-review-runner.toml`, `[ -f AGENTS.md ] && [ -f CLAUDE.md ]`.
  4. Cenário de migração: criar `.claude/skills/` como dir real com dummy → `kspec init` deve abortar (sem `--force`) e exibir plano.
  5. Idempotência: rodar `kspec update` 2× e diff de `find . -type l -ls` = 0.
- `scripts/prepublish-check.sh` executa:
  - Para cada symlink em `.claude/` e `.codex/`, valida `readlink -f` resolve para `.agents/...`.
  - Falha (exit 1) com mensagem clara se algum link estiver quebrado.
- `package.json#scripts.prepublishOnly` chama `npm run build && bash scripts/prepublish-check.sh`.
- Exit code claro: 0 = passou, !=0 = falhou.
</requirements>
